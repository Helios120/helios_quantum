Simple, clair, rassurant. Le client ne doit pas deviner le mode d’emploi.

2. Paiement

Vous envoyez le lien PayPal, Stripe ou le mode de paiement choisi.

3. Génération

Le thème est généré dans le logiciel HeliosAstro avec export PDF/PNG/GIF.

4. Livraison

Le client reçoit son fichier et, si prévu, une lecture écrite personnalisée.
